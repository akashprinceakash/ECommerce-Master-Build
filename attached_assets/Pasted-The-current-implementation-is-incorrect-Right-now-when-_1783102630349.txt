The current implementation is incorrect.

Right now, when a user drags a T-shirt or pants onto the avatar, the application simply overlays the uploaded PNG on top of the avatar. This produces an unrealistic result where the garment appears as a flat image instead of fitting naturally to the body.

Required Behavior

The clothing should behave like a texture or garment that conforms to the avatar's body.

For example:

When a T-shirt is dropped, its texture should be mapped onto the avatar's existing upper-body shirt mesh so it follows the body's shape, sleeves, chest, shoulders, and waist naturally.
When pants are dropped, the texture should be mapped onto the lower-body pants mesh so they wrap correctly around the legs and hips.
The clothing should stretch and deform with the avatar instead of remaining a rectangular PNG overlay.
Do NOT
❌ Place the PNG image on top of the avatar.
❌ Render the garment as a floating 2D image.
❌ Use absolute positioning to fake the clothing.
Expected Implementation

The system should use a proper avatar/clothing pipeline:

The avatar should have separate meshes/materials for:
Upper body (shirt)
Lower body (pants)
Shoes (optional)
When a clothing item is dropped:
Load the clothing texture.
Replace the material's diffuse/albedo texture on the corresponding mesh.
Keep the existing UV mapping so the texture wraps correctly around the body.
If using Three.js:
Replace the material's map on the shirt or pants mesh.
Update the material with material.needsUpdate = true.
Never create a new plane or sprite for the clothing.
If the clothing is provided as a full garment image instead of a texture, generate or use a UV-ready texture atlas before applying it to the mesh.
Goal

The final result should look like a real virtual try-on, where the clothing fits naturally to the avatar, similar to:

Ready Player Me
CLO 3D
Marvelous Designer
DressX
MetaHuman wardrobe systems

The clothing should appear as if it is actually being worn by the avatar, not pasted on top as a PNG overlay. This should be implemented using texture mapping/material replacement on the avatar's 3D model rather than image overlays.
