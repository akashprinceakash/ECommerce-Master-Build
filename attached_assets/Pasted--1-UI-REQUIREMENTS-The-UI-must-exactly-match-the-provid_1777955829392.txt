## 🧾 7. STYLE NUMBER LOGIC (VERY IMPORTANT)

### Format:

```
[STYLE] + [PRINT / COLOR] + [SIZE]
```

---

### A. STYLE CODE

* Example:

  ```
  KS1000B
  ```
* Rules:

  * T-shirt → ends with **B**
  * Pants → F
  * Shorts → S
  * Skirt → K

---

### B. PRINT CODE

* Format:

  ```
  GP001, GP002 ... GP032
  ```
* Example:

  ```
  KS1000B GP016
  ```

---

### C. SIZE CODE

#### If Standard:

```
S / M / L / XL
```

#### If Custom:

```
C
```

---

### Final Example:

```
KS1000B GP016 L
KS1000B GP016 C
```

---

### D. COLOR-BASED CUSTOMIZATION

If user selects colors instead of print:

```
KS1000B Grey Navy XL
KS1000B Black Red C
```
