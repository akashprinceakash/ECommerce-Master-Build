We need to improve the order management workflow and integrate automatic status synchronization with Shiprocket.

Current flow:

1. Customer places an order.
2. Payment is successfully verified.
3. Order is automatically created in Shiprocket.
4. Admin can see the order in both our application and Shiprocket.

Problem:
The client is unsure when order statuses should be updated manually. Since the order is already being pushed to Shiprocket, they expect shipment-related statuses to update automatically.

Required Changes:

1. Implement Shiprocket webhook integration to automatically sync order statuses with our application.

2. Map Shiprocket statuses to application statuses as follows:

   * AWB Assigned → Processing
   * Pickup Scheduled → Ready to Ship
   * Picked Up → Shipped
   * In Transit → In Transit
   * Out for Delivery → Out for Delivery
   * Delivered → Delivered
   * RTO → Returned
   * Cancelled → Cancelled

3. After payment verification:

   * Automatically mark the order as Confirmed/Paid.
   * Automatically create the order in Shiprocket.
   * Store Shiprocket Order ID and AWB details in our database.

4. When Shiprocket sends status updates through webhooks:

   * Update the order status in our application automatically.
   * Save tracking information and status history.
   * Show the latest tracking status to both admin and customer.

5. Add an Order Timeline section displaying:

   * Order Placed
   * Payment Verified
   * Order Created in Shiprocket
   * AWB Generated
   * Pickup Scheduled
   * Picked Up
   * In Transit
   * Out for Delivery
   * Delivered

6. Add a "Print Invoice" and "Print Shipping Label" option on the order details page if available from Shiprocket.

7. Ensure admins do not need to manually update shipment statuses once the order has been handed over to Shiprocket.

Please analyze the existing codebase and implement the complete end-to-end workflow, including webhook handling, database updates, error handling, and status synchronization.
