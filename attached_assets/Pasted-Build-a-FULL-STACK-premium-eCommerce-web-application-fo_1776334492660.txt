Build a FULL-STACK premium eCommerce web application for a luxury fashion brand named **KA.SHA**.

🎯 OBJECTIVE:
Create a high-end, production-level eCommerce platform similar in branding and experience to Malbon, combined with **Zakeke-level REALISTIC 3D product customization**.

This must NOT be a demo. It must be scalable, multi-product, and admin-manageable.

---

## 🎨 DESIGN & BRANDING

- Premium luxury UI (minimal, elegant, high-end fashion feel)

- Smooth transitions (no cheap animations)
- Clean modern typography (fashion brand style)
- Fully responsive (mobile + desktop)
- High-end visual polish (should feel like a real luxury brand)
- Use KA.SHA logo (provided later)

---

## 🏠 HOMEPAGE

- Strong hero section with brand identity
- Product listing (multi-product support)

Products include:
- T-Shirts
- Pants
- Future expandable categories

Each product card must:
- Display a **realistic 3D model preview (.glb)** (NOT static images)
- Use studio lighting and shadows
- NO cartoon-like rendering
- NO auto-rotation
- On hover:
  → subtle lighting shift / camera shift
- On click:
  → navigate to product page

---

## 👕 PRODUCT PAGE

- Large high-quality 3D viewer
- Drag to rotate
- Scroll to zoom
- Studio lighting (HDRI environment)
- NO auto-rotation
- Prominent button: **"Customize"**

## 🎛️ 3D CUSTOMIZATION (CORE FEATURE – ZAKEKE LEVEL)

Open full-screen premium customization interface.

### ✅ Color Customization
- Change base color
- Presets + custom color picker
- Real-time updates on 3D model

### ✅ Part Control
- Toggle ON/OFF:
  - Collar
  - Left Sleeve
  - Right Sleeve
- Must dynamically update mesh/material visibility

### ✅ Size Control
- S / M / L / XL
- Dynamically scale model

### ✅ Advanced Design System (VERY IMPORTANT)
- Use **2D Fabric.js canvas mapped onto 3D texture**

User can:
- Add text (font, size, color, style)
- Upload logos/images
- Drag, resize, rotate elements
- Add shapes:
  - Lines
  - Curves
  - Stripes
- Live sync canvas → 3D texture

### ✅ Live Preview
- Every change must reflect instantly on 3D model
