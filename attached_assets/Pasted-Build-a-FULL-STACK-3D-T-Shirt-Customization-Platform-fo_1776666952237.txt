Build a FULL-STACK 3D T-Shirt Customization Platform for a premium golf wear brand.

⚠️ THIS IS NOT A PROTOTYPE — Build production-level architecture.

--------------------------------------------------
🎯 CORE REQUIREMENTS
--------------------------------------------------

The system must allow:

1. ADMIN uploads .glb 3D models
2. USERS customize the t-shirt in REAL-TIME
3. 3D preview must use <model-viewer> (Google Model Viewer)
4. ALL customizations must reflect LIVE on the 3D model

5. 🚨 CRITICAL SAVE REQUIREMENT 🚨

When user clicks "SAVE":

→ The ENTIRE customized T-shirt must be saved and reproducible
→ NOT just the texture area
→ NOT just canvas JSON

The saved design MUST include:

✔ Base 3D model reference (.glb URL)
✔ Full texture image applied to model (PNG)
✔ Canvas design JSON (for editing)
✔ Model configuration (material index, placement, scale)

AND:

👉 When admin opens saved design:
→ The SAME 3D model must load
→ The SAME texture must be applied
→ The SAME final visual output must appear EXACTLY as user saw

--------------------------------------------------
🧱 TECH STACK (STRICT)
--------------------------------------------------


- <model-viewer> (Google)
- Fabric.js (design layer)



--------------------------------------------------
🧩 USER CUSTOMIZER ARCHITECTURE
--------------------------------------------------

Split into TWO SYNCHRONIZED LAYERS:

1. 2D DESIGN ENGINE (Fabric.js)
--------------------------------
- Add text (font, size, color)
- Upload logo/image
- Add shapes (rect, circle, lines)
- Drag / resize / rotate
- Add collar & sleeve styles
- Background color = t-shirt base color

2. 3D VIEW ENGINE (<model-viewer>)
--------------------------------
- Load .glb model
- Apply canvas texture dynamically
- Update texture ON EVERY CHANGE

--------------------------------------------------
🎨 REAL-TIME TEXTURE PIPELINE
--------------------------------------------------

On every canvas change:

1. canvas.toDataURL()
2. Convert → texture
3. Apply to model:

modelViewer.model.materials[0]
  .pbrMetallicRoughness
  .baseColorTexture
  .setTexture(texture)

→ MUST update in real-time (no refresh)



ALSO:

✔ Upload texture image to Cloudinary/S3
✔ Generate preview image (screenshot of model-viewer)

--------------------------------------------------
👨‍💼 ADMIN PANEL
--------------------------------------------------

Admin must:

1. View all saved designs
2. Click a design →
   - Load modelUrl
   - Apply textureUrl
   - Restore exact 3D appearance
