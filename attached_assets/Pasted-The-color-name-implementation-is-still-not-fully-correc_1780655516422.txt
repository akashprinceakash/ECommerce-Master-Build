The color name implementation is still not fully correct and requires further refinement.

### Current Issues Observed

1. **Color Name, Product Image, and Color Swatch Mismatch**

   * The displayed color name does not always match the actual T-shirt color shown in the product image.
   * The round color swatch displayed below the product also does not consistently match the product image or the color name.
   * For example, in the attached screenshots, some products display incorrect or incomplete color labels that do not correspond to the garment color being shown.

2. **Pattern Products**

   * Pattern products are not displaying any meaningful color or pattern description.
   * The current text appears incomplete or incorrect (e.g., showing partial text such as "ATTERN").
   * Customers should see a proper color/pattern description that helps identify the design.

3. **Printed Products**

   * Printed products are also not displaying a proper color description.
   * In several cases, only partial text is shown instead of a meaningful description.
   * Customers should be able to understand the primary color scheme of the print without relying on SKU codes.

### Production Requirement

As discussed previously, there will eventually be hundreds of print designs, and from a production perspective, it is important to continue maintaining internal identifiers such as:

* GP001
* GP002
* GP003
* etc.

These codes are useful for inventory, production, and order processing, but they are **not meaningful to customers** and should remain backend/internal references.

### Expected Frontend Behavior

* **Solid Products**

  * Display customer-friendly color names such as:

    * Navy
    * Black
    * Charcoal
    * Sage
    * Sky Blue
    * Pink
    * Cream
    * etc.

* **Printed Products**

  * Display a descriptive color name based on the print's color scheme.
  * Examples:

    * Navy Floral Print
    * Burgundy Paisley Print
    * Sage Floral Print
    * Blue Geometric Print

* **Pattern Products**

  * Display a meaningful pattern/color description rather than generic or truncated text.
  * Examples:

    * Sage Pattern
    * Cream Pattern
    * Sky Blue Pattern

### Final Requirement

Please ensure that for every product:

* The product image color, displayed color name, and color swatch always match.
* Pattern and printed products display meaningful customer-friendly color descriptions.
* Internal production codes (GP001, GP002, etc.) remain available in the backend for operational purposes but are not used as the primary customer-facing label.
* Verify the implementation on both product listing pages and product detail pages to ensure consistency across the entire site.
