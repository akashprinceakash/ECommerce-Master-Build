# 🛠️ 2. ADMIN SIDE (What YOU must do)

Once payment is successful, your backend must automatically:

---

## 🔁 A. Create Order in Database

From cart → order table:

Store:

* userId
* products
* quantity
* price breakdown
* paymentId (Razorpay)
* orderStatus = `"PAID"` or `"PROCESSING"`
* paymentStatus = `"SUCCESS"`

👉 This is your “source of truth”

---

## 📦 B. Inventory Deduction

Immediately:

* Reduce stock quantity
* Prevent overselling

---

## 🚚 C. Send Order to Shipping Provider

If you're using **Shiprocket**, this is the next big step:

### With Shiprocket:

You will:

1. Create shipment order via API
2. Send:

   * customer address
   * product weight/dimensions
   * payment mode (Prepaid)
3. Get:

   * AWB number
   * Courier partner
   * Tracking ID

Then store:

* trackingId
* courierName
* shippingStatus = “created”

---

## 💳 D. Payment Verification (VERY IMPORTANT)

From Razorpay:

You must verify payment using:

* Razorpay webhook OR
* backend signature verification

Then mark:

* `payment_verified = true`

⚠️ Never trust frontend success alone.
