Build the Lookbook to Match This Reference UI & Experience

The current Lookbook is functional, but it still feels artificial and does not provide enough value to customers when deciding what to purchase.

The goal is for users to feel confident that they are visualizing a complete outfit before buying. The Lookbook should resemble a professional fashion styling tool rather than a free-form drag-and-drop canvas.

Overall Design

Please use the attached reference image as the design and UX inspiration. The layout should be clean, premium, and fashion-focused, with the avatar centered and product panels on both sides.

1. Default Outfit

When the Lookbook opens:

Display a realistic Male avatar by default.
Dress the avatar in:
A plain white T-shirt.
A neutral navy or black pair of trousers.
This gives users a complete outfit immediately instead of an empty mannequin.
2. Product Categories

Organize products into categories.

Left Panel

Tops

Right Panel

Bottoms

(Additional categories such as Shoes, Jackets, Accessories can be added later.)

3. Replace Instead of Stack

Users should never manually position garments.

When the user selects another T-shirt:

The existing T-shirt should automatically be replaced.
The new T-shirt should inherit the correct position, scale, and alignment.

Similarly:

Selecting another pant should replace the existing pant.
Only one item per clothing category should exist on the avatar.

Example:

Current:
White T-shirt
Navy Trouser

↓

User clicks
Red Polo

↓

Result:
Red Polo
Navy Trouser

↓

User clicks
Grey Chino

↓

Result:
Red Polo
Grey Chino

No duplicate garments should appear.

4. Intelligent Garment Placement

This is the highest priority.

Do not simply overlay images.

Each garment should automatically snap into predefined body regions.

For example:

T-shirts align to the torso.
Pants align to the waist and legs.
Shoes align to the feet.
Jackets fit over tops.

Each category should have its own predefined placement zone.

There should be no manual adjustment required for normal use.

5. Realistic Scaling

The garments should look like they are actually being worn.

Avoid:

Floating clothes
Misaligned collars
Pants starting too high or too low
Different-sized garments

The outfit should look natural and proportional.

6. Background Removal

Every uploaded product should have its background removed automatically.

If background removal has already been processed during upload, use the transparent PNG/WebP version.

Only the garment should appear on the avatar.

7. Avatar

Replace the current mannequin with a more realistic fashion model similar to the reference.

Support:

Male
Female

Switching avatars should preserve the currently selected outfit where applicable.

8. User Experience

The workflow should be extremely simple.

Open Lookbook

↓

Default outfit already visible

↓

Click another T-shirt

↓

Automatically replaces current top

↓

Click another pant

↓

Automatically replaces current bottom

↓

Final outfit updates instantly

No dragging, rotating, resizing, or manual placement should be required for the standard experience.

9. Controls

Keep simple controls:

Zoom In
Zoom Out
Reset Outfit

These controls should always remain visible.

10. Performance
Load garments quickly.
Smooth transitions when replacing items.
No flickering.
Preserve aspect ratio.
Lazy-load product thumbnails.
11. Business Goal

The primary objective is not to build a design canvas.

The objective is to help customers confidently visualize complete outfits before purchasing.

The Lookbook should:

Feel premium and intuitive.
Encourage users to try multiple outfit combinations.
Increase engagement and conversion.
Help customers make purchasing decisions by showing how garments work together as a complete outfit.

Use the attached reference image as the primary design and interaction reference for the final implementation. The finished Lookbook should closely match its clean layout, automatic garment placement, realistic proportions, and polished shopping experience.
