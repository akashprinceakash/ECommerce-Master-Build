Fix the design placement system for the 3D t-shirt customization platform to ensure accurate, full coverage fitting on each garment part.

CORE REQUIREMENT:
The design must ALWAYS fit exactly within the selected garment part (Front, Back, Collar, Left Sleeve, Right Sleeve) without overflow, clipping, or partial placement.

STEP 1: PART SEGMENTATION (MANDATORY)
- Divide the 3D model into clearly defined sections using UV mapping:
  - Front
  - Back
  - Collar
  - Left Sleeve
  - Right Sleeve

- For each part, calculate and store:
  - UV bounding box (minU, maxU, minV, maxV)
  - Aspect ratio of the surface
  - Real mesh dimensions (width, height)

STEP 2: DESIGN FITTING LOGIC
When a user selects a design and clicks a part:

- Automatically scale the design to FIT the selected part using:
  - "cover" mode (fill entire area, no empty space)
  - Maintain aspect ratio
  - Center alignment by default

- If design aspect ratio differs:
  - Scale proportionally
  - Crop overflow inside UV bounds (not outside part)

STEP 3: FULL COVERAGE RULE
- The design must occupy 100% of the selected part area
- No half placement, no gaps
- No placement outside boundaries

STEP 4: PART-SPECIFIC BEHAVIOR

FRONT:
- Fit entire front torso area fully
- Respect chest-to-waist UV bounds

BACK:
- Fit entire back area

SLEEVES:
- Detect cylindrical mapping
- Wrap design correctly around sleeve
- No distortion or cut-off

COLLAR:
- Apply design only within collar UV region
- Handle curved geometry properly

STEP 5: DEFAULT SIZE FIX (IMPORTANT)
- When user selects a design initially:
  - Auto-scale it to fit the DEFAULT part (Front)
  - Do NOT use arbitrary size
  - Always use part dimensions

STEP 6: TRANSFORM CONTROLS (OPTIONAL BUT GOOD)
- Allow user to:
  - Scale (zoom in/out)
  - Rotate
  - Reposition (within bounds ONLY)

STEP 7: TECH IMPLEMENTATION NOTES
- Use UV mapping instead of screen coordinates
- Use Fabric.js canvas mapped as texture
- Sync canvas dimensions with UV bounds
- Apply texture via model-viewer or Three.js material

FINAL EXPECTED RESULT:
- Clicking "Front" → design perfectly fills entire front
- Clicking "Right Sleeve" → design perfectly wraps sleeve
- Clicking "Full Body" → apply design separately to ALL parts with correct fitting

NO PART SHOULD SHOW:
- Half design
- Misalignment
- Empty space
- Overflow outside mesh
