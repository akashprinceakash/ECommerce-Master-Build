Redesign and restructure the complete customization workflow for the KA.SHA Golf & Sportswear website to support two different customization entry flows and create a premium, seamless, luxury-level user experience similar to Nike By You, YDS, or high-end sportswear configurators.

The customization experience must feel modern, smooth, intelligent, visually premium, and extremely user-friendly.

────────────────────────────
MAIN REQUIREMENT
────────────────────────────

There should be TWO separate entry flows into the customization experience:

━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FLOW 1 — DIRECT CUSTOMIZATION ENTRY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

When the user clicks the main “Customize” button directly from the homepage/navigation/menu:

DO NOT directly redirect the user to the customization page.

Instead:

1. Show a premium modal/popup selection screen.

2. Ask the user:
   “What would you like to customize?”

3. Show 3 customization categories as large premium cards/buttons:

• Solid T-Shirts
• Pattern T-Shirts
• Printed T-Shirts

Each option should contain:

* preview image
* title
* short description
* hover animation
* luxury sportswear styling

After selecting a category, navigate the user to the customization page with the correct workflow and UI for that category.

────────────────────────────
A) PATTERN T-SHIRT CUSTOMIZATION FLOW
────────────────────────────

If the user selects “Pattern T-Shirts”:

The customization page flow should start with:

STEP 1:
Pattern Design Selection

* User first selects a pattern design/template.
* Show pattern thumbnails/cards.
* Allow live preview on the 3D t-shirt model.

IMPORTANT:
Do NOT show predefined color buttons.

Instead:
Provide 2 separate premium color pickers:

1. Body/Base Color Picker
2. Pattern/Texture Color Picker

The user should be able to fully customize both colors independently.

STEP 2:
Optional Prints Section

* User can optionally add prints on top of the pattern.
* Allow:
  • add print
  • remove print
  • replace print
  • resize print
  • reposition print

STEP 3:
Text & Logo Customization

Provide a dedicated section for:

* adding text
* adding logos

For BOTH text and logo:

* allow add/remove/replace
* allow resize
* allow drag/drop positioning
* allow placement part-by-part

Parts selection should work similarly to the current print placement system.

Supported placement areas:

* front center
* chest left
* chest right
* sleeves
* back upper
* back center
* collar
* side panels

User should visually select each garment section interactively.

────────────────────────────
B) SOLID T-SHIRT CUSTOMIZATION FLOW
────────────────────────────

If the user selects “Solid T-Shirts”:

STEP 1:
Color Customization

* Show premium color picker.
* Allow selecting colors for different t-shirt parts individually.

Examples:

* body
* sleeves
* collar
* side panels

STEP 2:
Print Customization

Allow:

* add/remove/replace prints
* resize prints
* reposition prints
  part by part or full body

STEP 3:
Text & Logo Customization

Allow:

* add/remove/replace text
* add/remove/replace logo
* resize
* drag/drop positioning
* part-by-part placement

Maintain the same placement selection system used for print positioning.

────────────────────────────
C) PRINTED T-SHIRT CUSTOMIZATION FLOW
────────────────────────────

If the user selects “Printed T-Shirts”:

STEP 1:
Show print/pattern templates first.

* Display available print-based t-shirt designs.
* User selects a print design/template.

OPTIONAL:
Allow adding pattern overlays on top of prints if desired.

STEP 2:
Print Management

Allow:

* add/remove prints
* replace prints
* resize
* reposition

STEP 3:
Text & Logo Customization

Allow:

* add/remove/replace text
* add/remove/replace logo
* resize
* reposition
* part-by-part placement

────────────────────────────
FLOW 2 — PRODUCT DETAIL PAGE PERSONALIZATION
────────────────────────────

When the user selects a t-shirt product from the product listing page and navigates to the Product Details Page:

Replace the existing button text:
“Customize”

WITH:
“Personalize This T-Shirt”

This flow is DIFFERENT from full customization.

When the user clicks:
“Personalize This T-Shirt”

Show a premium popup/modal with TWO options:

OPTION 1:
Quick Personalization

Description:

* Add text
* Add logo
* Place logo/text on selected parts
* Resize and reposition elements

This flow is ONLY for lightweight personalization.

OPTION 2:
Full Customization

Description:

* Complete design customization
* Colors
* Patterns
* Prints
* Text
* Logos
* Full garment editing

After selection:

The system should intelligently detect the selected product type from the product details page:

• Solid T-Shirt
• Pattern T-Shirt
• Printed T-Shirt

Then automatically redirect the user into the correct customization workflow.

Example:

* If the selected product is a pattern t-shirt → open Pattern Customization Flow
* If solid → open Solid Customization Flow
* If printed → open Printed Customization Flow

────────────────────────────
PERSONALIZATION FLOW REQUIREMENT
────────────────────────────

The “Quick Personalization” flow should ONLY focus on:

* adding/removing text
* adding/removing logos
* resizing
* repositioning
* selecting garment sections

This is specifically intended for client-requested personalization functionality.

No full design editing is needed in this flow.

────────────────────────────
UI / UX REQUIREMENTS
────────────────────────────

The overall experience must feel:

* premium
* luxurious
* smooth
* futuristic
* responsive
* production-ready

Include:

* smooth transitions
* animated panel switching
* modern popup modals
* premium cards
* hover animations
* live 3D preview updates
* responsive layout
* elegant typography
* clean spacing
* floating action sections
* sticky customization controls
* mobile-friendly interactions

The workflow should feel intuitive and guide the user step-by-step instead of overwhelming them with all controls at once.

Use a wizard/stepper-based layout for the customization flow.

The customization engine should dynamically show only the relevant controls based on:

* selected t-shirt type
* selected workflow
* selected customization stage

The experience should minimize clutter and maximize usability while maintaining a premium sportswear configurator feel.
